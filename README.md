# 🎮 Ping Pong — Cyberpunk Arcade Edition

A futuristic neon-glow **Ping Pong game engine** built with **HTML5 Canvas, JavaScript, and CSS**.  
Features smooth animations, AI opponents, particle effects, and a cyberpunk-inspired UI.

---

## ✨ Features
- **Game Modes**:  
  - 👫 Player vs Player (local two-player)  
  - 🤖 Player vs AI (easy, medium, hard)

- **Cyberpunk Theme**: Neon paddles, glowing ball, animated trails, and particle effects.

- **Dynamic Gameplay**:  
  - Ball speed increases with rallies  
  - Realistic paddle collision angles  
  - AI difficulty scaling with speed, reaction, and error margin

- **Responsive Design**: Works across desktop and mobile with touch controls.

- **Audio Engine**: Synthesized sound effects using the Web Audio API.
